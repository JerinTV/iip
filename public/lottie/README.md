Place your Lottie JSON files here:

- `gold-medal.json` (used in Awards → Gold Medal Recognition)
- `signing-contract.json` (used in Awards → ISBN Publication Opportunity)

The app loads them at runtime from:

- `/lottie/gold-medal.json`
- `/lottie/signing-contract.json`

If a file is missing or fails to load, the UI falls back to the static SVG icon.
